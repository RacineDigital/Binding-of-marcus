# Chapter soundtrack audio

Drop the chapter music files in this folder, named as they came, e.g. `01-cellar.ogg`,
`02-boiler.ogg` ... `30-home.ogg` (OGG preferred for the game; MP3 or MP4/M4A also work).

How to upload from the GitHub website:
1. Open this folder on GitHub (`assets/music/audio`).
2. Click **Add file → Upload files**, drag all the files in, and click **Commit changes**.

GitHub's website takes up to 25 MB per file and 100 files per upload.
